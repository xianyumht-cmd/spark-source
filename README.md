# spark-source

这是对用户提供的 Windows PE 文件进行源码恢复的工作仓库。仓库只记录文件结构、反编译证据、恢复脚本和已恢复数据，不讨论程序面向的具体业务。

## 当前结论

第一阶段静态恢复已完成：

- 确认为 32 位原生 Windows GUI PE；
- 版本资源明确显示由易语言编译；
- 原始 `.text`、`.rdata`、`.data` 节在磁盘文件中的 `RawSize` 均为 `0`；
- 磁盘入口先跳入高熵代码区，再进入统一的虚拟机调度路径；
- 已恢复 PE 布局、导入表、资源目录、清单、入口及调度器反汇编片段；
- 未执行目标文件，全部结果来自静态分析。

**当前仓库不是伪造的“完整源码”。** 现有磁盘镜像缺少原始代码节，且主要控制流被虚拟化，因此仅靠静态文件无法逐行还原原作者源码。仓库保留了可复现的第一阶段成果，并明确列出完成源码恢复所需的下一阶段数据。

## 目录

- `docs/analysis-report.md`：第一阶段技术报告；
- `docs/recovery-status.md`：已完成内容、缺口和下一阶段；
- `data/`：PE、导入表、资源与反汇编证据；
- `tools/`：可复现扫描与资源提取脚本；
- `src-recovered/`：目前能够可靠表达的入口伪代码和结构定义；
- `recovered/resources/`：可直接恢复的文本资源。
